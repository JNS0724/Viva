# 国际化

[English](internationalization.md) | 简体中文

## 语言行为

设置支持跟随系统、简体中文、English。新配置跟随系统；旧 preferences 文件没有 language 时保留中文。简体中文系统变体映射到 zh-CN，英语和其他未支持语言回退 en；繁体中文不冒充已支持翻译。界面语言与用户对话语言独立。

主进程保存选择，通过受校验的 IPC 广播到两个窗口。渲染器初始化完成后才显示文本。切换更新文案与缓存版本，不重载页面、不创建新 agent 会话、不清空对话。带 name/id 的表单草稿、选区、焦点和有 id 的滚动容器保留；输入法组合输入期间延后重绘。

## 资源

`src/shared/i18n/messages/en.ts` 定义有类型的键和参数，`zh-CN.ts` 必须键一致。`t()` 返回插值后的纯文本，DOM 仍通过文本节点构建。缺失键显示可读回退，并只记录一次键名，不记录用户参数。英文计数短语先对资源模板做单复数处理，再插入参数，不改写用户文字。日期和数字用 Intl，日历天差避免夏令时的小时数误差。原生托盘菜单使用同一进程语言。

界面字面量（含无障碍名称、校验、占位符、空态和错误）应进入资源。品牌、工具/协议 id、路径、用户输入、历史和第三方输出保留。主进程错误在创建时翻译，已捕获错误/历史不会随切换回译；全面改为 `{code, params}` 错误传输仍是独立兼容工作。

模型人设与插件指令不随界面切换。既有中文记忆合成标记、匹配规则、历史附件标记、旧字段迁移名称涉及兼容，不能当作 UI 批量替换；需要双语模型/fixture 验证和必要的数据迁移。界面国际化不代表英文记忆质量已经达到同等水平。

## 文档

默认 README/文档为英文，`.zh-CN.md` 为中文，相互导航。`AGENTS.md` 与图标说明采用单文件双语，避免规则分叉。历史报告保留日期、数量、证据边界和未运行项目。截图/录像仍为中文并明确标注，翻译说明不会改变媒体像素。

`docs/i18n-manifest.json` 保存已审阅文档对和规范化 SHA-256。`npm run check:i18n` 检查覆盖、相互导航、本地文件链接和新鲜度；测试套件也会运行。改文档后先审阅并同步另一语言，再记录两份新哈希；不得仅重算哈希绕过翻译审阅。检查能发现内容变化，不能证明语义等价或远端 URL 可用。

历史 QA 证据与注明日期的交接可在 `sourceReports` 中登记原语言和规范化 SHA-256，保留原始观察，不宣称已有翻译副本。只接受明确列出的 QA 报告/交接路径，内容变化会使审阅哈希失效；产品文档仍需已审阅的双语文档对。

## 消息源开发包与宣传

`viva-source new/test --language en|zh-CN` 默认英文。生成模板随所选语言，消息源自己提供的名称/内容仍属于源数据。包内包含双语 README、两套模板与编译后的共享翻译资源，运行时开发错误使用英文。

宣传字幕使用独立的有类型 React context/资源。Promo 默认英文，Remotion 参数 `--props='{"locale":"zh-CN"}'` 选择中文。现有截图/视频仍为中文，完整英文录像需要重新录制。安装器配置包含英文和简体中文，实际各平台安装运行仍需独立验收。

## 验证

运行 typecheck、完整测试、常规六阶段冒烟及 `smoke:language`。语言冒烟覆盖首次连接页/设置、未保存密钥草稿和选区焦点、连续切换、输入法延后更新、窄窗口、不变的会话身份、桌面岛同步。单测覆盖语言解析、旧配置迁移/持久化、IPC、资源键/参数、单复数、标签和日历天差；source-kit 测试验证模板和 CLI 语言。

发版还需 macOS、真实安装包启动/重启、两语言的流式/审批/错误状态、英文媒体录制，以及真模型双语记忆/插件行为。假模型与类型检查结果不能代替这些验收。
