# 新话题 P0 / P1 实现与验证

2026-10-26，Windows；分支 `codex/windows-island-interaction`，基于 `c4c13d73a429d00ab2262e14119a4cb92f276fa4` 的未提交工作区。运行时保持 Electron `44.7.0`、dsh `0.2.0-rc.2`、ACP SDK `1.9.0`。本轮不包含 P2 MCP 共享连接改造。

## 已完成

| 项目 | 实现 |
|---|---|
| P0 界面即时响应 | 点击后立即归档当前消息、显示新话题、聚焦可编辑输入框；准备中禁发送，失败显示重试并保留草稿；重复点击不重复创建，重试不重复归档 |
| P0 收尾移出等待路径 | 立即断开旧前台事件归属；无 MCP 或预热命中可与旧关闭并行；冷 MCP 创建和恢复仍等待释放；快速切换最多留一个旧前台收尾 |
| P0 阶段计时 | 主进程记录取消、关闭、等待释放、创建加 MCP 初始化、取得会话、命中来源、模型设置及总耗时；前端记录历史状态处理、渲染、界面响应、首帧回调和就绪 |
| P1 预热生命周期 | 一个备用会话；目录/配置指纹失效；就绪后 120 秒过期；同一失败指纹不反复预热；失败回退不污染正式 MCP 状态；清理失败可重试；dispose 后回收迟到结果 |
| P1 避免无效调用 | 空闲旧会话直接关闭，不额外取消；已选中的模型/选项不重复发送设置请求（主进程的 last-model 检查继续保留） |
| P1 长历史 | 按不可变 segment 缓存历史行，复用旧话题和消息 DOM，分组由重复数组复制改为线性追加；旧保存晚返回时回填归档 ID，不污染新话题 |
| P1 升级验证 | `0.2.1-rc.2` 在独立副本完成兼容、跨版本恢复和 Windows 打包运行时验证；主项目未升级，见 [升级报告](dsh-upgrade-validation-20261026.md) |

用户同时修改的后台任务行为已纳入：主对话只显示任务卡片，原始请求留在任务详情。补齐空对话卡片、后续首条主消息前的卡片锚点、旧话题迟到任务隔离和关闭清理；没有把原请求重新写成主对话用户气泡。

## 验证结果

- 四套 TypeScript 配置检查、构建和 `git diff --check` 通过。
- 固定 Electron 运行时执行完整测试：**640 passed / 0 failed**。覆盖冷 MCP 屏障、预热命中、失败重试、旧事件/权限/后续建议隔离、后台权限保持、备用过期、dispose 竞态、草稿和历史 ID。
- 真实 dsh + 本地假模型的流式、取消、单例 MCP、后台任务等测试通过；未调用外部模型或发送外部消息。
- 桌面五阶段冒烟 `setup / walkthrough / relaunch / memory / resume` 全部通过，使用专属测试用户目录。检查新话题即时焦点、禁发送和草稿保留，后台仅任务卡、详情原请求、任务重启恢复。
- 首轮完整测试及 memory 冒烟各发现一处旧断言要求后台用户气泡；按新契约更新后复测通过。首次 resume 的假模型随机端口与保存地址不一致；按仓库约定为 memory/resume 设置同一 `SMOKE_LLM_PORT` 后通过，没有改产品连接逻辑。

## 本次测量及范围

| 场景 | 结果 | 边界 |
|---|---|---|
| 桌面新话题点击 | 同步处理 4.5 ms；约 5.6 ms 时观察到就绪；输入立即聚焦且草稿保留 | 一次真实 Electron DOM 检查，使用假 ACP 后端；不是硬件点击到显示的延迟，也不是生产 p95 |
| 真实 dsh + 1500 ms 延迟 MCP，关闭预热 | 三次会话就绪 1638.56 / 1640.00 / 1636.29 ms | Node 驱动真实 dsh；包含旧关闭和新 MCP 初始化，不包含界面和模型生成 |
| 相同 MCP，等待预热成功再切换 | 三次接管 0.28 / 0.33 / 0.31 ms，均保留一个 active MCP | 只测桥接取得已有会话；初始化成本已在后台支付；不是本轮改动前后对照 |
| 1000 条 / 20 万字符历史，连续追加三个话题 | 初次创建 13.5 ms，三次追加约 0.2 ms；原话题和消息节点保持相同，旧子树 0 次 childList 变动 | 独立隐藏 Electron 页面，无完整产品 CSS；验证 DOM 构建与复用，不代表实际布局、绘制或显示延迟 |

主进程启用 `VIVA_SESSION_TIMING=1`，日志前缀为 `[session-timing]`；渲染器设置 `localStorage.setItem('viva:session-timing', '1')`，日志前缀为 `[session-timing:renderer]`。ACP 内部 MCP 初始化与 Agent 创建仍在同一 RPC 内，记录为 `session.create-and-mcp`，未伪拆阶段。首帧回调不等于 compositor 已呈现。

本机证据和可重跑驱动保存在 `E:\viva\new-topic-p0p1-20261026`：`verify.cjs`、五阶段日志和截图、`tests.log`、`benchmark.mjs` / `benchmark.json`、`dom-check.cjs` / `dom-check.json`。执行测试的 Node 启动器用 `ELECTRON_RUN_AS_NODE=1` 启动项目固定 Electron；GUI 冒烟移除此变量。TEMP/TMP 定向到测试目录。
