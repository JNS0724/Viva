# Viva 女仆角色设定

[English](maid-character.md) | 简体中文

Viva 的形象是一位蓝发女仆，素材来自 dsh-personal-agent 的 V4.1 道具状态版。她出现在首页、对话里当前这一轮、等你确认或回答的卡片、跟进事项的详情和桌面岛上。标题栏的岛不放她，只用状态色圆点，因为对话里已经有她了。界面上的配色和组件规则见[界面规范](ui-guidelines.zh-CN.md)。

## 角色识别特征

- 蓝色长卷发，发尾颜色渐浅；头顶一根环形呆毛。
- 白色荷叶边女仆头饰，画面右侧有一个蓝色蝴蝶结。
- 大而圆的蓝眼睛，Q 版比例，头大身小。
- 藏青色女仆裙，配白色围裙、领口和蝴蝶结。
- 状态靠她手里或头上的道具表达（见下表），不靠叠加的气泡或符号。

她的发色和藏青裙正好是 Viva 的强调色和底色，所以换形象不需要改界面色板。

## 应用素材

素材在 `src/assets/maid/`：

- 每个状态一张静图 `<状态>.webp`，400×400，从 512px 原图缩小导出。
- 问候、思考、回答中、提问、需要你确认另有动图 `<状态>-motion.webp`：问候是 400px、只播一遍；其余是 256px、循环播放。
- 原始 GIF、源图集和生成提示词留在 dsh-personal-agent 仓库，不放进 Viva。

素材自带米白底 `#FAF7F2`，没有透明通道。所以她的圆底就用同一个米白（`--maid-paper`），裁成圆形后看不出方形的边。这个米白只给她用，界面其他地方不用。

## 状态

| 状态 | 姿势和道具 | 动图 | 描边 | 什么时候 |
| --- | --- | --- | --- | --- |
| `greeting` 问候 | 挥手 | 有，只播一遍 | 蓝 | 启动后第一次显示首页 |
| `idle` 待命 | 捧着茶杯 | 无 | 平静 | 没事的时候 |
| `thinking` 思考 | 铅笔点下巴，抬眼 | 有 | 蓝 | 收到问题、还没开始写 |
| `typing` 回答中 | 戴方框眼镜敲键盘 | 有 | 蓝 | 流式回答、调用工具 |
| `ask` 提问 | 扶着耳麦侧头听 | 有 | 橙 | 助手在问你；文件拖到桌面岛上时也用它 |
| `confirm` 需要你确认 | 递出夹板 | 有 | 橙 | 审批卡片、桌面岛 |
| `done` 已完成 | 举起对勾卡 | 无 | 蓝 | 一轮结束、有准备好的事 |
| `error` 出错 | 拿着扳手检查 | 无 | 红 | 回答失败 |
| `offline` 连不上 | 看着断开的接头 | 无 | 灰 | 还没连上模型、正在连接 |
| `sleeping` 休眠 | 抱着枕头 | 无，轻轻呼吸 | 平静 | 后台准备进行中、你这边没事时 |

描边颜色和界面的状态色一致：橙表示在等你，红表示出错，蓝表示在工作或已完成。

## 显示规则

由 `src/renderer/view/maid.ts` 绘制：

- **取景**：`whole` 是整张半身图，用于首页 200px、确认卡片 96px、桌面岛 72px、跟进详情 64px。`face` 放大 1.6 倍、对准脸，用于对话里的 48px。
- **动图**只用在大尺寸、而且就在眼前的地方：首页问候、确认和提问卡片、展开的桌面岛、对话里当前这一轮。其他地方一律用静图。系统开了「减少动态效果」时，所有地方都用静图。
- **对话里**只有最新一轮的回答旁边有她。之前的回答保留 48px 的空位、不放头像，这样她移到新回答时，上面的文字不会跳动。卡片在等你时她在卡片上，回答旁边不再重复。
- **桌面岛**收起时是静图，展开后才动；`!`、`?`、`✓` 角标补上小尺寸下看不清的道具。
- **首页**外圈多一道浅浅的「茶托」边，这是整个界面里唯一大胆的地方，别处不加。
- 第一次画她时预先加载全部静图，之后换状态不会闪出空圆。
- 换图后，在首页、对话、确认卡片、跟进详情和桌面岛上都看一遍，并连续切换几个状态。
