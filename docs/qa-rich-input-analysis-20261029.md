## 输入请求没有中途停发

两组原生请求各 192 次。空闲的单次调用耗时 p50/p95/max 为 22/31/52ms，后台为 25/33/54ms；调用之间没有额外等待，后台最大空隙 1ms。

后台最长的 110ms 滚动位置更新间隔中，有两个调用完整开始并结束，另有前后两个调用与其重叠。该间隔内浏览器主线程执行了 68.943ms 的 WM_USER1024 消息，随后收到新的 DOM wheel。因此不能把整个 110ms 归为脚本暂停；但调用边界没有记录实际 SendInput 注入时刻和 OS 收件时刻，不能由此直接计算操作系统排队时延。

原生调用使用墙钟，页面使用 performance.timeOrigin；用 trace 结束标记校准，空闲/后台时钟偏差为 0.938/0.870ms。保留逐调用和逐间隔的对照，未只比较总体平均值。
