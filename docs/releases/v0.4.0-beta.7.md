Viva 0.4.0 beta 7 adds English and Simplified Chinese UI and improves reading continuity, background preparation and feedback.

## Downloads

| Platform | File |
|---|---|
| macOS (Apple silicon) | `Viva-0.4.0-beta.7-mac-arm64.dmg` |
| Windows (x64) | `Viva-0.4.0-beta.7-win-x64-setup.exe` |

Installers are unsigned. See the repository README for installation and first launch. Fully quit Viva before updating: closing its window may only hide it to the tray. Unfinished background tasks require manual resumption.

## Changes

- **English and Chinese UI:** follow the system language or choose English / Simplified Chinese in Settings. Switch without restarting; project documentation is available in both languages. This changes UI language and does not guarantee the language of model responses.
- **Keep your place while reading:** retain expanded answers, selection, focus, input drafts and reading position during background updates and language changes. Improve narrow-window stars and the new-content notice.
- **Complete background drafts:** truncated or interrupted preparation stays pending for retry instead of appearing ready. Show waiting reasons and preparation progress where the work appears.
- **Clearer permissions and memory:** display full permission parameters, distinguish connection startup from a conversation that cannot resume, identify partial memory-search results, and explain local storage and deletion scope.
- **Do not silently lose message batches:** incomplete, duplicate or foreign message IDs in a model judgment keep the batch pending for retry.

## Verification and known limits

- The merged fix candidate passed 803 unit/integration tests, strict typechecking, build and seven smoke phases. Installed Windows acceptance was also recorded. Release CI separately builds and tests the mounted macOS DMG and installed Windows application before publishing attachments.
- Real-model evidence remains bounded: the earlier complete 26-scenario run passed 25/26; after the fix, the two affected scenarios each passed three repetitions. This is not a new complete 26/26 run of this release.
- Extremely long answers and large process lists can still pause on first expansion. The 150 ms cold-expansion target is not met; these changes do not close the performance acceptance.
- Comprehensive physical fast-scroll and native interaction acceptance remains incomplete, including macOS device testing. Automated checks do not establish those manual cases as passed.
