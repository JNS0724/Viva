Viva 0.4.0 的新测试版（beta）：回答边生成边显示；长对话里发消息、交给后台更快；修了几处 Windows 上的问题。

[English](v0.4.0-beta.4.md) | 简体中文

## 下载

| 平台 | 文件 |
|---|---|
| macOS（Apple 芯片） | `Viva-0.4.0-beta.4-mac-arm64.dmg` |
| Windows（x64） | `Viva-0.4.0-beta.4-win-x64-setup.exe` |

## 安装包没有签名，首次打开需要多一步

- **macOS**：打开 dmg，把 Viva 拖进「应用程序」。第一次打开时，在「应用程序」里右键点 Viva →「打开」→ 再点「打开」。如果提示「已损坏」，在终端运行 `xattr -dr com.apple.quarantine /Applications/Viva.app` 后再打开。
- **Windows**：运行安装程序时如果出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

## 这一版的变化

- **回答边生成边显示**：模型写一段就显示一段，不用等整段写完。停止、重试、转到后台时，已经显示的内容和最终结果保持一致，不会重复，也不会丢字。
- **长对话更快**：对话很长时，点发送和输入都不卡；没变的消息不再整页重画。
- **「后台做」立刻有反应**：点了马上显示你的话和「正在准备后台任务」；没交上时内容保留，可以「重试」。
- **新话题打开更快**：接入了 MCP 时，会提前准备好下一个空话题。
- **修复**
  - Windows：桌面岛打开、关上输入框后会被别的窗口挡住，改成每次都重新置顶（还没在 Windows 真机上确认，遇到仍被挡住请告诉我们）。
  - Windows：鼠标停在桌面岛上时，后台数字和「打开窗口」按钮不再重叠。
  - 后台任务卡在一条命令上时，点「停下」后最多 8 秒就会结束，并提示那条命令可能还在运行。
  - 长回答时，最新的提问保持在顶部附近，窄窗口下也一样。

## 测试情况

- macOS 和 Windows：GitHub 上跑完了类型检查、全部测试和 5 段冒烟测试，并打包、静默安装、对装好的应用跑冒烟测试、卸载。
- Windows 真机：提速和流式显示在 175% 缩放下测过。
- 这一版还没有跑新加的真模型验证（`npm run live`，见 `docs/live-check.md`）。遇到问题请在 Issues 里告诉我们。
