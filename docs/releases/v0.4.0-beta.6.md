Viva 0.4.0 beta: fixes file permissions, background task recovery and input boundaries, with better narrow-window reading and error explanations.

## Downloads

| Platform | File |
|---|---|
| macOS (Apple silicon) | `Viva-0.4.0-beta.6-mac-arm64.dmg` |
| Windows (x64) | `Viva-0.4.0-beta.6-win-x64-setup.exe` |

Installers are unsigned. See the repository README for installation and first launch. Fully quit Viva before updating (closing the window may only hide it to the tray), then restart. Unfinished background tasks require manual resumption.

## Changes

- **Confirm access outside the workspace:** checks use real paths, including directory junctions. Generic shell commands also require approval in Workspace changes and Read only modes.
- **Find tasks after restart:** restore task records to their original conversation anchors and retain seen/dismissed state. Invalid or truncated background message judgments leave messages pending instead of silently losing reminders.
- **IME and drafts:** confirming an IME candidate no longer accidentally sends or closes input. Messages over 20,000 characters retain their draft and explain the limit; rejected task follow-ups retain input too.
- **Reading and errors:** fixes horizontal overflow in narrow/high-scale windows and isolates malformed image URLs so they cannot break the entire Markdown preview. Common model, credential and network errors have Chinese explanations in this release.
- **Model guidance:** improves memory lookup, table column consistency and MCP import instructions. Models can still produce inaccurate or incomplete content.
- **Installer integrity:** refreshes ASAR integrity metadata after final repacking, with cross-platform regression coverage.

## Verification and known limits

These are the recorded release checks from October 28–29, 2026, not new validation of subsequent branches.

- Windows: 770 unit/integration tests, strict typechecking and build passed.
- Installed Windows candidate: six smoke phases passed; all 26 real-model scenarios passed three repetitions each, with additional cross-feature, restart and input-boundary journeys.
- Release CI builds on macOS and Windows, runs smoke from the mounted DMG and installed Windows app, and publishes attachments only after all checks pass.
- **Expanding long answers can still pause briefly:** explicitly expanding an approximately 200 KB stress answer produced 94–289 ms long tasks. Steady scrolling afterward met the measured budget. Long-conversation rendering optimization is excluded from this release.
- Physical IME candidates, Explorer drag/drop, notifications/tray, sleep/wake, multiple displays and macOS device interaction have not completed comprehensive manual acceptance. CI and automation do not establish those checks as passed.
