Viva 0.4.0 的新测试版：修复文件权限、后台任务恢复和输入边界问题，改善窄窗口阅读与错误提示。

## 下载

| 平台 | 文件 |
|---|---|
| macOS（Apple 芯片） | `Viva-0.4.0-beta.6-mac-arm64.dmg` |
| Windows（x64） | `Viva-0.4.0-beta.6-win-x64-setup.exe` |

安装包尚未签名。安装与首次打开说明见仓库 README。更新前请完全退出 Viva（关闭主窗口可能只会退到托盘），更新后重新启动；未完成的后台任务需要手动恢复。

## 这一版的变化

- **工作区外文件先确认**：按真实路径检查文件访问边界，目录联接不能绕过确认；在“工作区修改”和“仅查看”模式下，通用 shell 命令也需要确认。
- **后台任务重启后仍能找到**：任务卡恢复到原对话位置，保留已读和关闭状态；后台消息判断遇到截断或坏格式时保留消息，避免静默漏提醒。
- **中文输入与草稿保护**：输入法确认候选时不再误发送或关闭输入；超过 20,000 字符时先提示并保留草稿，任务追问被拒绝后也保留输入。
- **阅读与错误提示**：修复窄窗口、高缩放下的横向溢出，异常图片地址不再让整个 Markdown 预览失败；常见模型、密钥和网络错误提供中文说明。
- **模型工具指导**：改善记忆检索、表格列数和 MCP 导入指导；模型仍可能生成不准确或格式不完整的内容。
- **安装包完整性**：最终重新打包后同步 ASAR 完整性记录，并补充跨平台回归检查。

## 测试情况与已知限制

- Windows 本地：770 项单元/集成测试、严格类型检查和构建通过。
- Windows 实际安装包：六阶段冒烟通过；完整 26 个真模型场景，每项重复 3 次全部通过，另有跨功能、重启和输入边界旅程验证。
- 发布流程在 macOS 和 Windows 构建安装包，分别从挂载的 DMG 和安装后的 Windows 应用执行冒烟；全部通过后才发布附件。
- **长回答展开仍可能短暂卡顿**：压力场景中，约 200KB 回答明确展开全文时出现 94–289ms 长任务；展开后的稳态滚动通过所测预算。长对话渲染优化未包含在本版。
- 实体输入法候选、Explorer 拖放、系统通知/托盘、睡眠唤醒、多显示器以及 macOS 实机交互未完成全面人工验收。CI 与自动化结果不代表这些项目已通过。

验收范围、修复和弱点见 [本轮验收记录](https://github.com/JNS0724/Viva/blob/main/docs/release-qa-20261028.md)。
