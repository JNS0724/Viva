# Viva 0.4.0-beta.5

[English](v0.4.0-beta.5.md) · [简体中文](v0.4.0-beta.5.zh-CN.md)

This Viva 0.4.0 beta adds queries for application background tasks and improves new-topic responsiveness and Windows desktop-island interaction.

Fully exit Viva before updating (closing the window may leave it in the tray), then restart to load new tools. Unfinished background tasks require manual resumption.

## Changes

- **Query background tasks:** list_background_tasks and get_background_task return current state, waiting reasons, and optional original requests/latest output. Queries are read-only and never approve or resume tasks.
- **Distinguish task types:** Viva tasks differ from command jobs, subagents, and goals. Empty unrelated lists do not prove Viva has no tasks. The main conversation queries its working directory; background sessions only query themselves.
- **Accurate interruption:** unresumed tasks after assistant exit or app restart are marked Interrupted instead of still running.
- **Responsive new topics:** show the input immediately while switching sessions in the background. Bound spare-session lifetime and failure retries; reduce repeated long-history rendering.
- **Simpler task cards:** background requests no longer add user bubbles to the main conversation; original requests remain in task details.
- **Island fixes:** improve Windows topmost and first-click behavior, leave time to drag before hover expansion, remove rectangular clipped shadows, and include the island in captures.

## Verification recorded for this release

- Local Windows: 649 tests, type checks, and build passed. Real embedded dsh with a local fake model verified query tools; background-task and restart/resume smoke passed.
- Desktop island: outer-shadow pixel checks passed for five states.
- Release workflows build installers on macOS and Windows and verify installed apps; attachments are published only after all checks pass.
- These model integration tests use a local fake model and do not establish reliable tool selection by every real model. The dsh dependency version was not upgraded.

## Download and first launch

| Platform | File |
|---|---|
| macOS (Apple silicon) | `Viva-0.4.0-beta.5-mac-arm64.dmg` |
| Windows (x64) | `Viva-0.4.0-beta.5-win-x64-setup.exe` |

Installers are unsigned. On macOS, drag Viva to Applications, then right-click → Open → Open. If reported as damaged, run `xattr -dr com.apple.quarantine /Applications/Viva.app`. On Windows, if SmartScreen appears, choose More info → Run anyway.
