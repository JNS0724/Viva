## 安装包没有签名，首次打开需要多一步

- **macOS**：打开 dmg，把 Viva 拖进「应用程序」。第一次打开时，在「应用程序」里右键点 Viva →「打开」→ 再点「打开」。如果提示「已损坏」，在终端运行 `xattr -dr com.apple.quarantine /Applications/Viva.app` 后再打开。
- **Windows**：运行安装程序时如果出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

## 这一版的变化

- **要我跟进吗？**：你说「周五前要交周报，到时候帮我起草」这类话，对话下面出现一张卡片，写明什么时候在后台准备、什么时候提醒你、会读哪些文件。你点「跟进」才算数。
- **后台准备**：在你选的时段（每天三次、两次、一次或自定义，工作日和周末分开），趁你不用电脑，把要跟进的事一起准备好。它只读、只起草：后台准备是一次不带任何工具的模型调用，材料里写什么都只当数据。准备好的在后台页「待你看的」里，「接着做」把草稿放进输入框。
- **消息源**：在设置里接入邮箱、告警、通讯工具。新消息在时段里一起判断，要你处理的成为一条建议，写明原消息和依据；说过两次「不重要」的发件人以后不再问。
- **不打扰**：提醒在你同意的时间发；准备好的只在你的间隙说（切回窗口、一轮对话结束、离开后回来），每天最多 3 次。电脑睡着时错过的提醒，醒来合并成一条。
- **今天**：每天第一次回到电脑前，汇总准备好几件、几条消息要你看、今天还要提醒几件；首页也有「今天」卡片。
- **文件变了就帮我**：「这个文件变了就帮我写改动摘要」，改完停稳 10 分钟后，排到下一个时段准备。
- **托盘和开机启动**：托盘显示几件等你看；设置里可以开机启动（默认关），开机后只留在托盘。
- **给开发者**：消息源是一个文件夹加一个程序，用什么语言写都行。附带 `viva-source-kit`（JS、Python、命令行模板和检查工具），协议见仓库里的 `docs/sources.md`。
- **README 和截图全部更新**，加了一段 40 秒的宣传片。

## 测试情况

- macOS：测试 574 个、5 段冒烟测试全部通过，包括真实 dsh 上的跟进全流程和消息源安装、拉取、移除。
- Windows：GitHub 上的 Windows 机器跑完了类型检查、全部测试和 5 段冒烟测试，并打包、静默安装、对装好的应用跑冒烟测试、卸载。**这一版还没在 Windows 真机上验证**（系统通知、托盘、开机启动、睡眠唤醒、4K 屏），遇到问题请在 Issues 里告诉我们。
