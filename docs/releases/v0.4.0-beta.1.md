# Viva 0.4.0-beta.1

[English](v0.4.0-beta.1.md) · [简体中文](v0.4.0-beta.1.zh-CN.md)

The first Viva 0.4.0 beta introduces proactive follow-ups: remember what you mention, prepare while you are away, tell you during a break, and continue only with your approval.

https://github.com/user-attachments/assets/14a56fd5-5b57-40f5-b02c-e2868b5dbf91

## Changes

- **Follow-up cards:** specify preparation time, reminder time, and files to read. Only clicking Follow up makes a proposal active.
- **Background preparation:** three, two, one, or custom daily windows, separately for weekdays/weekends. Runs while you are idle. A model call without tools reads materials only as data and returns a draft. Continue places it into the input from the Background page.
- **Sources:** connect email, alerts, and messaging. Scheduled batch review creates suggestions with source text and reasons. After two Not important decisions for a sender, no further suggestions from that sender.
- **Quiet reminders:** agreed reminders arrive at their time; prepared work is announced during a break (returning to the window, finishing a turn, or returning after being away), at most three times daily. Reminders missed during sleep are combined on waking.
- **Today:** a daily summary of ready drafts, messages to review, and upcoming reminders, also shown on the home page.
- **Watch files:** after ten quiet minutes following a change, prepare in the next window.
- **Tray and login:** tray shows pending items. Optional start at login (off by default) starts in the tray only.
- **Developer sources:** any-language program plus a manifest. Includes viva-source-kit with JS, Python, and command templates and validation; see ../sources.md.
- **Updated README and screenshots**, plus a 40-second promotional video.

- Windows: GitHub runners passed type checks, all tests, five smoke phases, packaging, silent installation, installed-app smoke, and uninstall. **This release had not yet been validated on a physical Windows machine** for system notifications, tray, startup, sleep/wake, or 4K displays. ## Download and first launch

| Platform | File |
|---|---|
| macOS (Apple silicon) | `Viva-0.4.0-beta.1-mac-arm64.dmg` |
| Windows (x64) | `Viva-0.4.0-beta.1-win-x64-setup.exe` |

Installers are unsigned. On macOS, drag Viva to Applications, then right-click → Open → Open. If reported as damaged, run `xattr -dr com.apple.quarantine /Applications/Viva.app`. On Windows, if SmartScreen appears, choose More info → Run anyway.
