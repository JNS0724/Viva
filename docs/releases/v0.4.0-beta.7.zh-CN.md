## 变化

- **英文与中文界面：** 跟随系统语言，或在设置中选择英文／简体中文，无需重启即可切换。项目文档提供双语版本。此设置改变界面语言，不保证模型回复所用的语言。
- **阅读时保留原位置：** 后台更新和切换语言时，保留已展开的正文、选区、焦点、输入草稿和阅读位置；改进窄窗收藏入口及新内容提示。
- **后台草稿完整后才准备好：** 截断或中断的准备保留待重试，不再显示为成品；在相关位置说明等待原因和准备进度。
- **权限与记忆说明更清楚：** 完整显示权限参数，区分连接启动中与无法继续的话题，标明部分记忆搜索结果，并解释本地存储和删除范围。
- **消息批次不再被静默漏掉：** 模型判断缺少消息、重复消息或包含批次外 ID 时，整批保留待重试。

## 验证与已知限制

- 已合入的修复候选通过 803 项单元／集成测试、严格类型检查、构建及七阶段冒烟，并记录了 Windows 实际安装验收。发布 CI 会另行构建并测试挂载的 macOS DMG 和 Windows 实际安装应用，全部通过后才发布附件。
- 真模型证据仍有边界：此前完整 26 场景为 25/26；修复后，两项受影响场景各通过三次复测。这不代表本次版本重新全量通过 26/26。
- 极长正文和大量过程首次展开仍可能停顿，150ms 冷展开目标尚未满足，本次改动不代表完整性能验收通过。
- 物理快滚和原生交互的完整人工验收仍未完成，包括 Mac 实机测试；自动检查不能代替这些人工验收。
