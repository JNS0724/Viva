# Viva 0.4.0-beta.4

[English](v0.4.0-beta.4.md) · [简体中文](v0.4.0-beta.4.zh-CN.md)

This Viva 0.4.0 beta streams answers as they are generated, improves long-conversation and background-task responsiveness, and fixes Windows issues.

## Changes

- **Live streaming:** text appears as the model writes. Stop, retry, and background transitions reconcile displayed content with the final result, without repetition or missing text.
- **Long conversations:** sending and typing stay responsive; unchanged messages are not redrawn wholesale.
- **Immediate background feedback:** clicking Run in background immediately shows the request and preparation state. Failed submissions keep the content and offer Retry.
- **Faster topics:** with MCP connected, the next empty session can be prepared in advance.
- **Windows island:** reapply topmost after opening/closing the input. At publication this specific fix had not been confirmed on a physical Windows machine; report continued occlusion. Hover background counts no longer overlap Open window.
- **Stuck commands:** stopping a background task ends the wait within eight seconds and warns that the underlying command may still be running.
- **Long answers:** the latest question stays near the top, including in narrow windows.

## Verification recorded for this release

- macOS and Windows GitHub runners passed type checks, all tests, five smoke phases, packaging, silent installation, installed-app smoke, and uninstall.
- Physical Windows: responsiveness and streaming checked at 175% scaling.
- The newly added real-model validation (npm run live; ../live-check.md) had not yet run for this release. Please report issues.

## Download and first launch

| Platform | File |
|---|---|
| macOS (Apple silicon) | `Viva-0.4.0-beta.4-mac-arm64.dmg` |
| Windows (x64) | `Viva-0.4.0-beta.4-win-x64-setup.exe` |

Installers are unsigned. On macOS, drag Viva to Applications, then right-click → Open → Open. If reported as damaged, run `xattr -dr com.apple.quarantine /Applications/Viva.app`. On Windows, if SmartScreen appears, choose More info → Run anyway.

These are historical release notes, not verification of the current checkout.
